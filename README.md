# BrainfuckOnTeX

8時間クオリティのインターフェース。

ファイルを読み込み、本文で
```tex
\brainfuck{++++++++++[>+++++++>++++++++++>+++>+<<<<-]>++.>+.+++++++..+++.>++.<<+++++++++++++++.>.+++.------.--------.>+.}
```
のように記述すると`Hello World!'と出力されます。構文は以下の通りです。
```tex
\brainfuck[<input>]{<code>}
```
`\char'を使用するため、使用環境によってはグリフの出力がうまくいかない可能性があります。
